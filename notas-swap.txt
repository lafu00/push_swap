Para implementar las operaciones de swap (sa, sb, ss) de forma ultra-eficiente sobre nuestra estructura t_stack, modificaremos directamente los punteros de la lista enlazada doble.
El movimiento consiste en intercambiar los dos primeros nodos de la cima del stack. Como nuestros nodos no son circulares (tienen NULL al final o extremos lineales), el intercambio debe rehacer los enlaces next y prev de los dos primeros nodos y del tercero si existiera.
Para cumplir la Norma de 42 y evitar duplicar código, crearemos una única función lógica interna (swap) que trabaje con un puntero doble t_node **head. Luego, las funciones oficiales (sa, sb, ss) simplemente la llamarán, imprimirán su comando y actualizarán las estadísticas del benchmark en O(1).
Aquí tienes el archivo swap.c completo y 100% normativo (menos de 25 líneas por función):

📄 Archivo swap.c

c
#include "push_swap.h"

// 1. Función lógica pura: Intercambia los 2 primeros nodos de cualquier stack
static void	swap(t_node **head)
{
	t_node	*first;
	t_node	*second;

	if (!head || !*head || !(*head)->next)
		return ;
	first = *head;
	second = first->next;
	first->next = second->next;
	if (second->next)
		second->next->prev = first;
	second->prev = NULL;
	second->next = first;
	first->prev = second;
	*head = second;
}

// 2. Operación SA: Intercambia los 2 primeros elementos del Stack A
void	sa(t_stack *stack, int silent)
{
	if (stack->size_a < 2)
		return ;
	swap(&(stack->a));
	if (!silent)
	{
		write(1, "sa\n", 3);
		stack->op_count++;
		stack->op_stats[0]++; // Supongamos que el índice 0 es para 'sa'
	}
}

// 3. Operación SB: Intercambia los 2 primeros elementos del Stack B
void	sb(t_stack *stack, int silent)
{
	if (stack->size_b < 2)
		return ;
	swap(&(stack->b));
	if (!silent)
	{
		write(1, "sb\n", 3);
		stack->op_count++;
		stack->op_stats[1]++; // Supongamos que el índice 1 es para 'sb'
	}
}

// 4. Operación SS: Ejecuta SA y SB al mismo tiempo
void	ss(t_stack *stack)
{
	int	executed;

	executed = 0;
	if (stack->size_a >= 2)
	{
		sa(stack, 1);
		executed = 1;
	}
	if (stack->size_b >= 2)
	{
		sb(stack, 1);
		executed = 1;
	}
	if (executed)
	{
		write(1, "ss\n", 3);
		stack->op_count++;
		stack->op_stats[2]++; // Supongamos que el índice 2 es para 'ss'
	}
}

💡 Detalles clave de la implementación:

• El parámetro silent: Permite reutilizar sa y sb dentro de la función ss sin que impriman sus textos individuales en la consola ni alteren los contadores por separado. De esta forma, si se ejecuta ss, solo se imprime una línea y cuenta como una sola operación, tal como exige el subject.
• Seguridad de punteros: La lógica comprueba si el tercer elemento existe (if (second->next)) para reconfigurar su puntero prev hacia el nuevo segundo elemento, evitando cualquier caída por desreferenciación ilegal (Segmentation Fault).

2. Función base swap_nodes (Lista doblemente enlazada)

Al tener un puntero prev en cada nodo, al intercambiar el primero y el segundo tienes que actualizar cuatro enlaces (además de la cabeza de la pila y el puntero last si solo había dos nodos).
c
static int	swap_nodes(t_node **top, t_node **last)
{
	t_node	*first;
	t_node	*second;

	if (!top || !*top || !(*top)->next)
		return (0);
	first = *top;
	second = first->next;
	first->next = second->next;
	if (second->next)
		second->next->prev = first;
	else if (last)
		*last = first;
	second->prev = NULL;
	second->next = first;
	first->prev = second;
	*top = second;
	return (1);
}
Usa el código con precaución.
• Retorno int: Devuelve 1 si el intercambio se realizó y 0 si no había suficientes nodos. Esto evita sumar operaciones falsas a tus contadores si se llama a sa con 0 o 1 elemento.
• Cuidado con last: En tu t_stack tienes un solo puntero last (asumo que es para top_a). Si top_a tenía exactamente 2 nodos y haces sa, el que era primero pasa a ser el último, por eso actualizamos *last = first. Para top_b puedes pasar NULL en ese parámetro.

3. Implementación de sa, sb y ss con contadores

Ahora cada movimiento actualiza tus estadísticas en t_stack e imprime la instrucción (si no estás en modo silencioso o según cómo manejes bench_mode):
c
void	sa(t_stack *stack, int print)
{
	if (!stack || !swap_nodes(&stack->top_a, &stack->last))
		return ;
	stack->count_op++;
	stack->static_op[OP_SA]++;
	if (print)
		write(1, "sa\n", 3);
}

void	sb(t_stack *stack, int print)
{
	if (!stack || !swap_nodes(&stack->top_b, NULL))
		return ;
	stack->count_op++;
	stack->static_op[OP_SB]++;
	if (print)
		write(1, "sb\n", 3);
}

void	ss(t_stack *stack, int print)
{
	int	done_a;
	int	done_b;

	if (!stack)
		return ;
	done_a = swap_nodes(&stack->top_a, &stack->last);
	done_b = swap_nodes(&stack->top_b, NULL);
	if (!done_a && !done_b)
		return ;
	stack->count_op++;
	stack->static_op[OP_SS]++;
	if (print)
		write(1, "ss\n", 3);
}

Detalles clave a vigilar

• Inicialización: Antes de empezar a contar, asegúrate de inicializar count_op = 0 y poner a 0 las 11 posiciones de static_op (por ejemplo con ft_bzero(stack->static_op, sizeof(long) * 11)).
• Conteo en ss: Fíjate que ss llama directamente a swap_nodes y no a sa() y sb(). Si llamaras a sa() y sb() dentro de ss(), sumarías 3 operaciones al contador (sa + sb + ss) en lugar de 1 sola (ss).
